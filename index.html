Esta página web fue creada como parte de una actividad para practicar la estructura básica de HTML y las características principales de HTML5.

HTML permite crear y organizar el contenido que se muestra dentro de los navegadores web.

¿Qué es HTML5?

Características principales

HTML5 es una versión moderna de HTML que introduce elementos semánticos y permite trabajar con contenido multimedia directamente desde el navegador.

Algunas etiquetas importantes

  • header
  • nav
  • main
  • section
  • article
  • figure
  • footer

Puedes obtener más información visitando MDN Web Docs .
