Assessment 3.1 - Creación de una página web básica

Esta actividad consiste en desarrollar una página web básica utilizando
HTML5 y CSS.

La página contiene una estructura semántica utilizando elementos como
header, nav, main, section, article y footer.

También se utilizaron características de HTML5 como video, audio,
canvas, figure y figcaption.

El diseño visual de la página se realizó utilizando un archivo CSS
externo.

La página fue desarrollada utilizando Visual Studio Code y probada
utilizando un navegador web.

El proyecto también fue almacenado en un repositorio de GitHub.
